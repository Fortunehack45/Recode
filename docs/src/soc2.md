# SOC2 & Enterprise Security

Recode is actively preparing for SOC 2 Type 1 and Type 2 compliance certification to satisfy the security requirements of our enterprise customers.

Recode's security principles are built on:
- **Local-First Processing**: Source code and file buffers never leave your machine without explicit direction.
- **Strict Access Controls**: Granular role-based permissions for enterprise team management.
- **Data Encryption**: All transit communications use TLS 1.3 with authenticated cryptographic protocols.
- **Air-Gapped AI Support**: Full support for offline local AI models (such as Ollama) with zero network exposure.

For enterprise compliance reports, vendor security questionnaires, or inquiries, please contact [security@recode.dev](mailto:security@recode.dev).
